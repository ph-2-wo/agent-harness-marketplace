# これまでの指示が受け止められているかを確かめる

あなたは呼び出し元の会話を見ていない。材料はトランスクリプト・ファイル・コマンドから取る。
結果を表で返す。登録は呼び出し元がするので、あなたはしない。

## 1. 指示を書き出す

呼び出し元が渡した path がトランスクリプト。無ければ `ls -t ~/.claude/projects/*/${CLAUDE_SESSION_ID}.jsonl` の先頭。
`type` が `user` の行のうち、テキストが `<` で始まらない発言を、古いものから全部書き出して番号を振る。
時刻を渡されたら、その時刻より後の発言だけにする。

- 1つの発言に指示が複数あれば、分けて番号を振る
- 原文の語を残す。言い換えない

## 2. 受け皿を出す

`node "${CLAUDE_SKILL_DIR}/../create-next-action/scripts/na.mjs" list --session ${CLAUDE_SESSION_ID}` で、未処理のアクション・依頼・後回しを出す。

## 3. 指示ごとに受け皿を当てる

1 の番号ごとに、次のどれか1つを書く。

- 済み: 済んだことを示す所在（commit・ファイル:行・URL・トランスクリプトのツール結果）。実際に開いて確かめる
- 載っている: A・R・D の番号
- 無い

次に当たるものは、済みではなく無いにする。

- 所在を書けない
- 「今は」「現時点では」「一旦」と付けないと済みと言えない
- 指示の一部しか済んでいない。済んだ部分と残りに分けて書く

## 4. 受け皿が指示と食い違っていないかを見る

未処理のアクション・依頼・後回しを1件ずつ、1 のすべての指示と照らす。
ある指示が退けた案や、ある指示が付けた条件に反するものを、食い違いとして書く。

## 5. 返す

番号・指示の原文・受け皿・所在の表で返す。無いものを表の先頭にまとめる。
食い違いは表とは別に、受け皿の番号・指示の番号・どこが食い違うかで返す。
