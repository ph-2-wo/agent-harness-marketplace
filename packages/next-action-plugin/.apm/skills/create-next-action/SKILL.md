# ネクストアクション

承認が要るものは、応答の末尾に「ネクストアクション」として次の形で列挙する

- `A1`: 何をするか
  - 予想: ok 高
  - 要否: 要 高
  - ok: 使うスキルか手順
  - ng: 使うスキルか手順

番号は「英大文字＋数字」の形で振る（A1 など）
- 英字を付けるのは、応答の中のほかの番号（手順や要求の列挙、案の中の選択肢）や、ユーザーの返事の数字と取り違えないため。`1.` `2.` の番号付きリストで書かない
- 英字は A から使う。別の英字を使ってもよい（質問を Q1 とする、など）
番号は指示メモごとに振り、その指示メモの中では使い回さない
- ok 済み・取り下げ済み・差し戻しの番号も、使ったものとして数える。次は、指示メモに記録した最大の番号の続きから振る（A1〜A3 の後は A4）
- 案を直したら、元の番号ではなく新しい番号を振る
- 例や、案の中の小さな選択肢には番号を振らない

承認が要る事項が無いときは、アクションを作らず「ネクストアクションはありません」と書く

## 予想

各アクションに、次の2つの予想を書く

- 予想: ユーザーが ok と返す見込み。必ず `ok 高` `ok 中` `ok 低` のどれかで書く
- 要否: 聞かずに実行したらユーザーが困る見込み。必ず `要 高` `要 中` `要 低` のどれかで書く

ng になりそうなときは `ng 高` ではなく `ok 低`、困らなさそうなときは `不要 高` ではなく `要 低` と書く
ok 中・ok 低なら、ok にならないと思う点を1行添える
返事が来たら、予想と実際の返事を指示メモの解釈に1行残す（例 `A3: 予想 ok 高 → ok`）
要否は、ユーザーが要否に触れたときだけ残す（例 `A3: 要否 要 低 → 要`）

今の段階で承認できるものをアクションとする

- 今出せるアクションは1回の応答にまとめて出す。1つずつ小出しにしない
- 承認されたアクションが複数あるときは、1つずつサブエージェントに出して並行で進める
- 実行内容が検討済みならそれを、でなければその検討をアクションとする
- 検討をすぐできるなら検討してから出す
- 前に出したアクションは、出し直す前に「今それをやって、判断が変わるか」を確かめる
  - 変わらないなら、自分で取り下げる
