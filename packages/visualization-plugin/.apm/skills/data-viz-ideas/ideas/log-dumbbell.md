# 対数目盛の2点線（log-dumbbell）

## いつ使うか

桁の違う値（API の価格が 0.1〜50 ドルなど）を、多数の行で比べるとき。
1行に2つで1組の値（入力と出力の価格など）がある場合に向く。

## 何を解決するか

等間隔の目盛りだと、安い行が左端に潰れて差が見えない。
2つの値を別々の棒にすると、行の数が倍になり読みにくい。
対数目盛にして、1行の2つの値を線で結ぶ。

## 作り方の要点

- 横軸は対数目盛にする。
  目盛りは10倍ごと（$0.1、$1、$10）に置き、「1目盛りで10倍」と凡例に書く
- 入力を白丸、出力を黒丸にし、2つを線で結ぶ
- 時間帯などで変わる価格は、印を一方の値（オフピークなど）に置き、もう一方までの幅を薄い帯で示す
- 注目する行（主役のモデル）は、行の背景に色を付け、印もその色にする
- 注目する行を先頭に置き、残りは値の小さい順に並べる。
  右端に関連する値（最大コンテキストなど）を文字で出す

## 落とし穴

- 割引の期限や、キャッシュに当たらない場合の値か、などの条件は図に入らない。
  注記に書く
