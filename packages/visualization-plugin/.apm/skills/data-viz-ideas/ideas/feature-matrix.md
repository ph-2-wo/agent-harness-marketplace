# 印つきの機能表（feature-matrix）

## いつ使うか

方式の違いや機能の有無など、数値でなく文字で表す違いを比べるとき。

## 何を解決するか

文字の違いは、点や棒に置き換えても意味が出ない。
ただの表のままだと、どこが変わったのかを全セル読まないと分からない。
表の形は残し、セルを丸いラベルにして、新しくなった所だけに色を付ける。

## 作り方の要点

- 行が項目、列がモデルの表のままにする
- セルの中身を丸いラベル（角丸の小さな囲み）にする
- 新しくなった所（主役のモデルで前と違う所）だけ色を付け、太字にする。
  変わっていない所は薄い灰色のラベルにする
- 狭い画面では表に最小幅を付け、表を包む要素だけを横スクロールさせる（ページ全体は横に広げない）

## 落とし穴

- 色付きのラベルが増えると、どこが新しいかが分からなくなる。
  色は「変わった所」だけに使う
