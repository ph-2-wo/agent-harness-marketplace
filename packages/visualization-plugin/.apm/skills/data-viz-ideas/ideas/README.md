# アイデアの振り分け

## 見せたいもの → アイデア

| 見せたいもの | アイデア |
| :-- | :-- |
| 多数のモデル×多数の項目の点数（全体像と1つずつを同時に） | [dot-rows-focus](dot-rows-focus.md) |
| 点数が狭い範囲（90 付近など）に固まって差が見えない | [row-zoom-toggle](row-zoom-toggle.md) |
| 測った条件が違う値（各社の自己申告値など）も参考に並べたい | [hollow-overlay](hollow-overlay.md) |
| 1つの変数を動かしたときの量の推移 | [linked-slider-chart](linked-slider-chart.md) |
| 少数のモデルの量（パラメータ数・層数など）の比較 | [quantity-bars](quantity-bars.md) |
| 方式や有無など、文字で表す違い | [feature-matrix](feature-matrix.md) |
| 桁が違う値の比較（価格など）、2つで1組の値 | [log-dumbbell](log-dumbbell.md) |
| 2〜3か国などの同じ統計の推移を、分類ごとに比べる | [small-multiple-lines](small-multiple-lines.md) |

## 共通の決まり

- 補足の説明や一覧は `<details>` で閉じておく
- 大きな図は、縦か横のどちらか一方だけでスクロールさせる。
  両方出るなら向きを変える
- 図に置き換えた元の表は消さず、`<details>` に畳んで残す
- 系列を色で分けるときは、`dataviz` スキルの validate_palette で `--pairs all` を付けて検証する。
  7色は通らなかったので、会社（グループ）を色で、同じ会社の中を形で分けた
- スマホ幅（400px）で開き、`document.documentElement.scrollWidth` が画面幅を超えないことを確かめる

## 合わなかった案

ユーザーに差し戻された、または検討して捨てた見せ方。
同じ場面で再び出さない。

- 順位の推移の線: 順位だけになり、点差が消える
- 多角形（レーダー）の重ね合わせ: 軸の並べ方で印象が変わる。
  7つ重ねると読めない
- 平行座標: 線が交差しすぎて読めない
- 分野ごとの平均: 分野の分け方が恣意的で、平均すると差が消える
- 色の濃淡のマス目（ヒートマップ）: 色から数値を読むことになる
- 2モデルの差の棒: 主役を選べる点の図（dot-rows-focus）で足りる
- 率を身近な金額に直す（「ある時点の一定額が今いくらに当たるか」）: 総合の1つの値しか載らず、推移も見えない
