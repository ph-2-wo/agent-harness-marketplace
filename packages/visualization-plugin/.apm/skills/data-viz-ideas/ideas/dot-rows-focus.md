# 主役を選べる点の行（dot-rows-focus）

## いつ使うか

多数のモデル×多数の項目（ベンチマークなど）の点数を比べるとき。
0〜100 のように共通の目盛りで測れる値に向く。

## 何を解決するか

表は1つずつの値は読めるが、全体像が見えない。
棒グラフにすると、項目ごとに1本ずつしか並ばず、全体像と1つずつを同時に見られない。
1行に全モデルを点で置くと、全体の分布が1画面に収まる。
主役を選ぶと、その1モデルが全項目でどこにいるかを追える。

## 作り方の要点

- 1行が1項目、1つの点が1モデル。
  横軸は 0〜100 で全行共通にする
- モデル名のチップを押すと、そのモデルが主役になる。
  主役の印は大きくし、黒い縁を付ける
- 主役以外の点も、灰色にせずモデルの色のまま残す（灰色は見分けにくい）。
  選んだかどうかは大きさで分かる
- 行の右端に、主役の順位を `k/n`（n は値のあるモデル数）で出す。
  1位は強調する
- 行を押すと開き、その行の値の範囲に拡大した一覧を出す。
  値の高い順にモデル名・点・数字を並べ、値の無いモデルは「値なし」と書く
- レーティングなど単位の違う項目は図から外し、値を注記に書く
- 値の無いモデルは点を置かない。
  部分集合での値などは「42.0†」のように文字列で持たせ、注記で記号を説明する

## 落とし穴

- 7色を全組で区別できる色の組はなかった。
  会社（グループ）を色で、同じ会社の中を形（●■▲）で分けた
- 行を開いたときの一覧は、図の上の共通の目盛りとは範囲が違う。
  拡大した範囲の両端の数字を一覧の上に出す
