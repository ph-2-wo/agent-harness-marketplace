# 行ごとに拡大する切り替え（row-zoom-toggle）

## いつ使うか

[dot-rows-focus](dot-rows-focus.md) のような行の図で、点数が 90 付近などの狭い範囲に固まっている行があるとき。

## 何を解決するか

0〜100 の共通の目盛りだと、固まった点の差が見えない。
かといって拡大だけにすると、行をまたいだ全体像が失われる。
2つの表示を切り替えられるようにして、両方を残す。

## 作り方の要点

- 「0〜100 で全体」と「行ごとに拡大」の2つのボタンで切り替える。
  押されている方は `aria-pressed` で示す
- 拡大では、行ごとに値の最小〜最大（少し余白を足す）を両端にする。
  最小を切り捨てて −1、最大を切り上げて +1 し、0〜100 に収める
- 拡大では、行の両端に最低・最高の数字を小さく出す。
  目盛りの見出しも「行ごとの最低／最高」に替える
- 重ねる値（[hollow-overlay](hollow-overlay.md)）を出しているときは、その値も範囲に含める
- 拡大中は行をまたいで位置を比べられないことを、図の注記に書く

## 落とし穴

- 拡大した図で、行をまたいで点の位置を比べると読み違える。
  注記を省かない
