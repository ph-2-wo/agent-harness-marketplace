# 分類ごとの小さな推移の図（small-multiple-lines）

## いつ使うか

2〜3か国など少数の系列で、同じ統計の推移を比べるとき。
総合・中身の分類（食品とエネルギーを除く、ガソリンなど）のように、項目ごとに桁や幅が違う場合に向く。

## 何を解決するか

最新月の値を並べるだけだと、差が広がっているのか縮んでいるのかが分からない。
全部の分類を1枚の線の図に入れると、桁の違う項目（ガソリンの 34% など）が他を潰す。
分類ごとに小さな線の図を縦に並べ、図ごとに目盛りを持たせる。

## 作り方の要点

- 1分類1図。図ごとに目盛りを決め、目盛りが違うことは見出しで分かるようにする
- 系列の色は名前で決め、どの図でも同じ名前は同じ色にする（カードの中で最初に出た順）
- 右端に各系列の最新値（欠けた月を除く最後の値）を点と文字で出す。文字は系列の色でなく本文の色
- 欠けた月（未公表・調査なし）は線を切る
- 0 を跨ぐ図は 0 の線を少し濃くする
- 比べる系列の定義をそろえる（米国の食品とエネルギーを除く ↔ 日本の生鮮食品とエネルギーを除く）。そろえられないものは見出しに書く

## 落とし穴

- 図ごとに目盛りが違うので、図をまたいで線の高さを比べられない
- 自分で計算した値（指数からの前年比など）は見出しに「私の計算」と書く
