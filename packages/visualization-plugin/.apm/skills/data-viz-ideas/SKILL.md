# Data Viz Ideas

使って通った見せ方のアイデアから、今のデータに合うものを選ぶ。

色の検証、軸や目盛りなどの作り込みは、このスキルでは扱わない。
組み込みの `dataviz` スキルを使う。

## 手順

1. `ideas/README.md` を読み、「見せたいもの」の列が今のデータに当たる行のアイデアを選ぶ。
   複数当たれば組み合わせる。
   「合わなかった案」に当たる見せ方は選ばない
2. 選んだ `ideas/<name>.md` を読む
3. そのファイルに「見本」の節があれば、そこにある id を `reference/` の HTML で grep し、その要素と、ファイルに名前の出てくる関数を読む
4. 作ったものに、表に無い見せ方が入っていて、ユーザーが差し戻さずに受け入れたら、`ideas/` に1ファイル足し、`ideas/README.md` の表に1行足す。
   見出しは既存のアイデアにそろえ、見本のページがあれば `reference/` に写しを置く
5. ユーザーに差し戻された見せ方は、`ideas/README.md` の「合わなかった案」に理由と一緒に足す

4 と 5 は、この skill を配っている package の `.apm/skills/data-viz-ideas/` を直す。
展開先の `.claude/skills/` を直しても、次の `apm install` で消える。
