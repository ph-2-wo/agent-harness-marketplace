# 状況から始める並び（context-first-order）

## 場面

読み手が初めて見る話を説明し、判断を求めるとき。

結論から始めると、前提を知らないまま結論を読むことになり、頭に入らない。

## 作り方

- 状況 → 問題と問い → 案（選択肢）→ 根拠 の順に並べる
- 結論は [pinned-question-header](pinned-question-header.md) の見出しに置き、最初から見えるようにする。
  並びの先頭には置かない

## 使わない場面

- 同じ話の続き・出し直し。
  [changes-first-revisit](changes-first-revisit.md) を使う
- 読み手が既に状況を知っているとき。
  状況は短くするか飛ばせるようにする

## 根拠

- Bransford & Johnson 1972「Contextual prerequisites for understanding」: 文章の前に文脈を渡すと理解と再生が上がり、後に渡すと大きく下がった。
  要旨で確認し、本文は読めていない。
  https://paperguide.ai/papers/06070657-76e0-4355-b53c-5dfe9979bf2f/
- Minto の SCQA: Pyramid Principle の冒頭は Situation・Complication・Question・Answer の順で、答えはその後。
  二次の解説。
  https://scqa.lifeitself.org
- expertise reversal effect: 既に知っている人には、補助が逆効果になりうる。
  「使わない場面」の理由。
  https://www.uky.edu/~gmswan3/EDC608/Kalyuga2007_Article_ExpertiseReversalEffectAndItsI.pdf

## 事例

- 結論のカードから始めた束は、頭に入らないとして差し戻された
- 状況から並べ替え、結論を固定の見出しに置いた束は通った

## 確かめた回数

- 使って通った: 1回
- 前例: 3件（1件は要旨だけ、1件は二次）
