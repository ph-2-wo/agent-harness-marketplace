# 一覧で選んでまとめて消す（bulk-select-list）

## 場面

溜まった項目のうち、古いものや要らないものをまとめて消すとき。

1件ずつ開いて消す形だと、件数だけ操作が要る。
「これ以外を消す」だけだと、残したい古い項目を守れない。

## 作り方

- 「整理」のボタンで、項目の一覧を全画面で開く
- 各行は、左にチェック、日付・題名と、消すかの判断に要る数（コメント件数など）
- 行のメニューに「これより古いも全部選ぶ」を置く。その行も含める
- 下に赤いボタン1つ。文言に、実際に消える件数と量を入れる
- 押したら、消えるものを書いた確認を1段挟む
- 中身を持つ項目は、中身を先に消し、項目の行を最後に消す。途中で止まっても項目が一覧に残り、消し直せる
- どの項目にも載っていない中身があれば、一覧の先頭に行を出し、同じように選んで消せるようにする
- 消す間は、ボタンに進み具合を出す

## 使わない場面

- 1件だけ消す操作。今1タップで届くなら、一覧に畳まない

## 根拠

前例なし。

## 事例

- 動画・音声フィードバックの Artifact に足したページの整理は、差し戻しなしで通った
- 最初の版は、選んだページの行を先に全部消していた。削除の途中で画面を戻ると、動画 80 本がどのページにも載らず画面から消せなくなった。消す順・取り残しの行・進み具合を足して直した
