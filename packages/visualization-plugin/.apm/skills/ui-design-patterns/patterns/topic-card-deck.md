# 1カード1トピックの束（topic-card-deck）

## 場面

判断や説明のために、1つの画面で多くのこと（結論・理由・前例・懸念など）を見せたいとき。

1画面に全部を詰めると、収めるために理由や根拠を削ることになる。
区切りも優先度も無く縦に並べると、何を見てほしいかが決まらない。

## 作り方

- 1枚のカードに1つのトピックだけを置く
- カードの大きさを決め、1枚の情報量が1画面を超えないようにする
- 大きさが決まっているので、カードは横に送る
- カードの上端に、そのカードの主張を言い切った一文を置く。
  本文は、それを支える証拠（図・差分・数値など）1つにする
- 比べたいもの同士は別のカードに分けず、1枚の中に並べる
- カードの中が少し縦に伸びるのは許す。
  上端に一文があれば、伸びても何の話かは分かる
- 束の上には [pinned-question-header](pinned-question-header.md) を置く

## 使わない場面

- 頭から順に読む読み物（文書・レポート）
- 見せることが1つで、1画面に収まるもの
- 比べたいものだけで中身が終わるもの（1枚に並べる）

## 根拠

- assertion-evidence slides: 見出しは言い切った主張、本文はそれを支える視覚的な証拠1つ。
  効果は小さいという批判もある。
  https://www.assertion-evidence.com/
- Healey の preattentive processing の解説: 画面が切り替わると、前の画面との違いに気づけない（change blindness）。
  比べるものを同じカードに並べる理由。
  https://www.csc2.ncsu.edu/faculty/healey/PP/
- NN/g: 人はスクロールするが、注意は画面の上に偏る。
  カードの上端に一文を置く理由。
  https://www.nngroup.com/articles/scrolling-and-attention/

## 事例

- 判断を求める画面で、結論・理由・選択肢を1画面に詰めた見本は、理由が一文に削られて差し戻された
- 縦に並ぶカードを詰めた見本は、何を見てほしいかが分からないとして差し戻された
- 大きさの決まったカードを横に送る束にした見本は通った
