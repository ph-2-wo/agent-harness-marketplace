# 変わったところを先に出す出し直し（changes-first-revisit）

## 場面

一度見せたものを直して、もう一度見せるとき（2回目以降）。

毎回状況から読ませると、読み手は知っている前提を読み直すことになる。
変わったところが他と同じ見た目だと、どこが新しいかを探すことになる。

## 作り方

- 前の版から変わったところ（差分）を先頭に置く
- 変わったカードには「新」「変更」の印を付ける
- 変わっていないカードは後ろに薄く出し、参照できるように残す
- 初めて見る読み手もいるなら、「初めて見る」と「前の版を見た後」の見せ方を切り替えられるようにする

## 使わない場面

- 初めて見る読み手だけのとき。
  [context-first-order](context-first-order.md) を使う

## 根拠

- expertise reversal effect: 既に知っている人には、補助が逆効果になりうる。
  https://www.uky.edu/~gmswan3/EDC608/Kalyuga2007_Article_ExpertiseReversalEffectAndItsI.pdf
- Healey の preattentive processing の解説: 見てほしい所に1つだけ違う特徴を付けると、一瞥で気づける。
  https://www.csc2.ncsu.edu/faculty/healey/PP/

## 事例

- 出し直した束を状況から始めた見本は、変わったところだけ知りたいとして差し戻された
- 差分と変わったカードを印付きで先頭に出した見本は通った

## 確かめた回数

- 使って通った: 1回
- 前例: 2件
