# 問いと案を固定した見出し（pinned-question-header）

## 場面

[topic-card-deck](topic-card-deck.md) のようなカードの束を、1枚ずつ送っていくとき。

状況や前提から始まるカードは、それが何の話につながるのかが分からない。
1枚目に目次を置いても、送った先では見えなくなる。

## 作り方

- 全カードの上に、問いと案（結論）を固定して出す
- その下に、カードの進み具合の線を出す
- 進み具合の線は、カードを送る向きに合わせる。
  横に送るなら横、縦に送るならカードの横に縦で出す
- 固定の見出しと進み具合の線があれば、1枚目の目次は外す

## 使わない場面

- カードが1枚だけのとき

## 根拠

前例なし。
進み具合の線を送る向きに合わせるのは、短い動画を横に送る画面（線も横）に倣った推測で、出典は開いていない。

## 事例

- 状況から始まる束の上に問いと案を固定した見本は、前提から始まっても何の話か追える形として通った

## 確かめた回数

- 使って通った: 1回
- 前例: なし（ユーザーの発言だけに拠る）
