# data-viz-ideas

表データ・数値データをグラフィカルに見せるときに、見せたいものから使える見せ方のアイデアを引く。

## 解決する課題

比較表を図にしたい、多数のモデル×多数の項目を比べたい、値の推移を見せたい、という場面は繰り返し来る。
そのたびに agent が見せ方をゼロから考えると、前に差し戻された案（順位の推移の線、多角形の重ね合わせなど）をまた出す。
通った見せ方の細部（主役の選び方、拡大の切り替え、条件の違う値の重ね方）も、毎回ユーザーに直されてから入る。

## 概要

skill 本体は振り分けだけを持ち、知見はアイデアのファイルに置く。

- `ideas/README.md`: 見せたいもの → アイデアの振り分け表、共通の決まり、合わなかった案とその理由
- `ideas/<name>.md`: アイデア1件につき1ファイル。
  いつ使うか・作り方の要点・見本の場所・落とし穴
- `reference/`: アイデアが実際に使われたページの写し（見本）。見本を配布していないアイデアもある

使って満足された新しい見せ方は、`ideas/` に1ファイル足して README に1行足す。
この保守を通して、この skill を使う人の間で知見を共有する。

## 利用場面

表データ・数値データをグラフィカルに見せる方法を決めるとき。

仕組みやアーキテクチャの図は対象外。
色の検証やグラフの作り込みは、組み込みの `dataviz` skill を使う。

## 依存

skill 間の依存はなし。
