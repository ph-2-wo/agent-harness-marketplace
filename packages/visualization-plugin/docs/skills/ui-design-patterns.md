# ui-design-patterns

人が見て操作する画面・ページを作る、直すときに、画面の場面から使って通った UI のパターンを引く。

## 解決する課題

判断を求める画面、スマホで操作する画面、複数の項目を順に見せる画面は、繰り返し来る。
そのたびに agent が画面の作りをゼロから考えると、前に差し戻された作り（情報の詰め込み、画面下に何段も重ねた操作、絵文字のアイコンなど）をまた出す。
通った作りの細部（見せる順序、親指の届く位置への操作の置き方、既存の画面への寄せ方）も、毎回ユーザーに直されてから入る。

## 概要

skill 本体は振り分けの手順だけを持ち、知見はパターンのファイルに置く。

- `patterns/README.md`: 場面 → パターンの振り分け表、共通の決まり、合わなかった案とその理由
- `patterns/<name>.md`: パターン1件につき1ファイル。
  場面・作り方・使わない場面・根拠・事例・確かめた回数

使って通った新しい作りは、`patterns/` に1ファイル足して README に1行足す。
差し戻された作りは、README の「合わなかった案」に理由と一緒に足す。
この保守を通して、この skill を使う人の間で知見を共有する。

## 利用場面

人が見て操作する画面・ページを作る、直すとき。
判断を求める画面、スマホで操作する画面、複数の項目を順に見せる画面などが当たる。

表データ・数値データを図にする見せ方は対象外。
`data-viz-ideas` skill を使う。

## 依存

skill 間の依存はなし。
