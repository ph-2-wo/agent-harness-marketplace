# 新しいセッションへの引き継ぎ

引き継ぎの文面は、何についてキャッチアップするかを伝える2〜3行だけにする。

```
<話題>についてキャッチアップしてください。
```

話題は、記録の中で使っている言葉で書く。
経緯・決定・注意点・次にやることは書かない。

今のエフォートは `${CLAUDE_EFFORT}`。
これが high 以上（high・xhigh・max）のとき、または新しいセッションの仕事を high 以上で進めたいときは、`create_session` で立てない。
ユーザーに、今のセッションと同じリポジトリで新しいセッションを立て、エフォートを選び、引き継ぎの文面を送ってもらうよう依頼する。
`create_session` には、エフォートを指定する引数が無い。

`create_session` で立てるときは、今のセッションのリポジトリを `source_url` に渡す。
渡さないとリポジトリの無いセッションが立ち、記録を読めない。
