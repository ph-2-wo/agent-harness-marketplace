# 新しいセッションへの引き継ぎ

引き継ぎの文面は、何についてキャッチアップするかを伝える2〜3行だけにする。

```
<話題>についてキャッチアップしてください。
```

経緯・決定・注意点・次にやることは書かない。

引き継ぎの文面に書く言葉は、正式名称で書き、指す先を特定する。

- 正式名称で書く
  - 概念・仕組み・部品は、その分野で通っている名前で書く（environment や「環境」でなく環境変数）
  - 正式名称が無い・出典で確かめられないときは、何を指すかを説明する句で書き、そう書いたことを示す
    - 別の分野の名前を借りるなら、借りたと書く
  - 記録や周りの文書にある語でも、正式名称でなければ直す
- 指す先を特定する
  - 同じ種類が他にもあるなら、どれかまで書く（どこに設定した環境変数か）

`create_session` で立てるときは、次の2つを渡す。

- `effort`: 今のエフォート（`${CLAUDE_EFFORT}`）
  - 新しいセッションの仕事を別のエフォートで進めたいときは、ユーザーに聞いてから、そのエフォートを渡す
- `source_url`: 今のセッションのリポジトリ
  - 渡さないとリポジトリの無いセッションが立ち、記録を読めない
