# 経緯のキャッチアップ

直近の記録から、その前提になった議論の記録まで遡り、当初の依頼の原文にたどり着くまで読む。
このスキルで読む記録は、サブエージェントに出さず自分で読む。

## 1. 起点を集める

話題の言葉で、記憶ディレクトリ全体を本文検索する（テーマのディレクトリで絞らない）。

```bash
grep -rln "<話題の言葉>" <記憶ディレクトリ>/
```

ヒットしたファイルを日付順に並べ、どのテーマのディレクトリに散っているかを見る。
言葉を変えて2〜3回検索する（例: 「後回し」「延期」「defer」）。

## 2. 直近を読む

いちばん新しい記録と、そのセッションの指示メモを読む。

## 3. 前提を辿って遡る

読んだファイルから、前提にしているものを書き出す。
- 出典として書かれたファイル・行
- 「〜の続き」「〜で決めた」「〜で積み残し」と書かれた件
- 別のセッションの識別子

それぞれの出典を読み、そこでまた前提を書き出す。これを繰り返す。
出典が書かれていなければ、その件の言葉で検索し、より古い記録を読む。

次のどちらかで止める。
- その話を始めたユーザーの発言（当初の依頼の原文）に着いた
- 新しい前提が出てこなくなった

## 4. 出すものと照らす

読んだ記録から、決まったこと・退けた案・議論した論点を書き出す。
これから出す説明・案を、書き出したものと1つずつ照らす。
触れていないものがあれば、触れてから出す。
