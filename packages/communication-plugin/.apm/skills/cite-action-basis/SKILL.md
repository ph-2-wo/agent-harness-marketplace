# 行動と指示の文面の対応を示す

対象は、依頼で指定された行動とする。会話中のどの時点の行動でもよい。
指定が無ければ、直前の応答で行った行動を対象にする。

対象: $ARGUMENTS

## 照合する文面

会話に既に入っている、次の文面だけを照合する。
ファイルを開いて探さない。

- CLAUDE.md
- `.claude/rules/` の指示
- スキルの本文
- hook の出力
- Claude Code 本体の指示
- ユーザーの発言

## 書き方

行動ごとに次の3項目を書く。

- 行動: 何をしたか
- 出どころ: ファイル名、スキル名、hook の名前、または「ユーザーの発言」
- 引用: 対応する文面を一字一句そのまま

対応する文面が会話に無ければ、出どころと引用の代わりに「会話に対応する文面なし」と書く。
