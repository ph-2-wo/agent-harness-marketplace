# zero

前提知識のない読み手に向けて、説明・提案・報告を書く。

## 解決する課題

agent はその会話で積み上げた文脈を持ったまま文章を書く。読み手も同じ文脈を持っている前提になるので、
指示語、その場で決めた略称、経緯を知らないと意味の取れない参照がそのまま残る。

書いた本人には読める。読み手には読めない。他メンバーへの依頼、社外向けの文章、
後から読まれる記録で、この差がそのまま伝達の失敗になる。

## 概要

その文章だけで読み手が判断できる状態にする書き方を扱う。

## 利用場面

「1から100まで伝わるように」「前提を知らない人にも分かるように」「経緯を知らない人向けに」と
言われたとき。他メンバー・社外向けの文章や、後から読まれる説明を書くとき。
`organized-explain` から呼ばれる。

## 依存

なし。
