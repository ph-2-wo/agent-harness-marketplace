## 飛躍は模倣から作る

改善を重ねても届かない理由は `philosophy.md` にある。

飛躍は何もないところからは生まれない。
他の実例（種）を今の課題に結びつけて作る。
種は必要になってから探すだけでは足りない。
だから、ふだんから貯めておく。

## 種を貯める

課題とは関係なく、目を引いた事例に触れたら `memory/leap-seeds/` に1件1ファイルで書く。
書くのは「何をしたか」と「何が効いたか」の2つ。

## 飛躍を出す

1. 種を集める。実例を、分野を散らしてたくさん挙げる。
   ぱっと見、今の課題と関連するかどうかは関係しない。
   出どころは次の3つ。
   - `memory/leap-seeds/` に貯めた種
   - 検索して見つけた実例
   - 自分の知識から挙げた実例
2. 結びつける。種ごとに「これを今の課題に持ち込むと何になるか」を書く。ここでは評価しない。
3. 見出す。結びつけた中から、今の前提を変える案で、有用なものを選ぶ。
