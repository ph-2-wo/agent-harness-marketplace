---
name: structured-refactor
description: 情報を構造的に整理する手順を提供する
---

対象の情報を宣言する
- 長い場合は一時ファイルに記載する
  - 置き場所はスクラッチパッド。ファイル名は `refactor-` で始める（例 `refactor-target.md`）
  - サブエージェントでは `analysis` `summary` などで始まる `.md` の Write が Claude Code に止められる。`refactor-` で始めればこれに当たらない
対象の情報を1行ずつ分析する
- 1行ずつ性質を書き出す
- 別の行との親子関係等を Index を使って示す
分析された構造に基づいて、組み替えを有効に使う
- 階層リストやテーブルを有効に使う
- ここで情報を増やさない
- 一時ファイルは途中の材料。組み替えた結果は応答に書く。ファイルを指すだけで済ませない
