# Harness 手順化

以下の1と2をループする
打ち止めになったら3でまとめる

## 1. 具体性評価

- 対象全行について1行ずつチェック
  - その行に具体的なやり方のわからないものが含まれるかを判定

### 判定例

- 「そう書いてあるけど具体的にどうすればいいの？」の答えが書いてない
- 思考・判断なら、それで良いかどうかを測る基準がない
- 実行なら実行対象を特定できる情報がない
- 分散していて何から取り掛かっていいかがわからない

## 2. 具体化

課題のある点について解決策を選んで実行する

### 2-A. Stepにわけれそうならわける

- 明確にStepにわかれている文章をわけないままにしている
  - 例: XXX して YYY する
- 暗黙的にStepにわけられる
  - 例: 何かを見つける＝見渡す＋判断する２ステップ
  - 例: あるいは大規模な時は集計する＋判断するの２ステップも有用そう

ひとまず分けるだけ分ける
具体的に成立するところまでは考えず次のループに任せる

### 2-B. 手順に使えそうな情報が整理されていない

- 同じことを言っている情報がまとまっていない
  - 例: Stepの分離の話が明示的な事例と暗黙的な事例があるのでまとめておきたい
- 手順として別の階層にあるべきものがフラットに並んでいる
  - 例: ループの話と、そのループの中でとるべき手段の話は階層構造

ひとまずその部分だけ整理する

### 2-X. 上に当てはまるものがもうなく手詰まり

- 具体化を進めるかどうかに着目して選択肢を並べる
  - 選択肢例
    - 打ち止め
    - 頑張って進める
    - 部分的にできることを見つける
      - 例: 例示によるFew shotで妥協
- コストとリターンを考える
  - コスト評価例
    - 実装する: 大
    - 考える: 中
    - 書く: 小
  - リターン評価例
    - 具体的なイメージがなくてできるかわからない: 期待値が不明瞭、ゼロかマイナス
    - 具体的なイメージがあって実現可能そう: ゼロからプラス

## 3. まとめて返却

ここまで作れたものを使える形にまとめる
なにかをつけたしたりせず形を整えるだけ
