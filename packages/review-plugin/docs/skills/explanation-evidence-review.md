# explanation-evidence-review

agent が書いた説明を、書いた本人とは別のサブエージェントが、1文ずつ一次情報に照らして確かめる。

## 解決する課題

説明を書いた本人は、確かめたつもりになっている。
記憶や推測が、事実の顔をして説明に混ざる。
本人に見直させても、同じ思い込みのまま読み返すので見つからない。

## 概要

- **集める**: 呼び出し元のトランスクリプトから、ユーザーに見せた説明を集める
- **分ける**: 1文ずつに分け、事実・推測・意見に分類する
- **照らす**: 事実の文に、コードベース・公式の出典・ツールの結果を実際に開いて当てる
- **返す**: 裏付けあり・根拠不足・食い違いの判定を、所在つきの表で返す

説明は直さない。直すのは呼び出し元。

## 利用場面

`realign-with-original-request` から呼ばれたとき。自分の説明に根拠が足りているかを確かめるとき。

## 実行の形

`context: fork` だけを指定する。
別のコンテキストで走るので、書いた本人の思い込みを引き継がない。
agent と background は既定のままにする。

## 依存

なし。
