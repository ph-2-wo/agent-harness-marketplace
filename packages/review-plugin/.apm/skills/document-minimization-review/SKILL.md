# Document Minimization Review

対象文書から、消せる可能性がある記述を全て消したベースラインを再構成し、余分な記述のない本文を提案する。

編集はせず提案として返す。

## Workflow

### 1. 対象範囲を設定

新規作成したものであれば全体を対象とする。

改善したものであれば改善箇所を対象とする。

対象を全体的に掃除する指示の場合は全体を対象とする。

### 2. 消せる可能性があるかを1行ずつ判定

対象ファイルの対象箇所全行について、消せる可能性があるかないかのみを判定する。

消した方がいい、消したら困る、では判定しない。

迷った行は可能性があるに倒す。

### 3. 断捨離してベースラインを作成

可能性があると判定した箇所を全て消した本文を作る。

これをベースラインとする。

ベースラインは文書として成立していなくてよい。

成立させるための書き足しをここでしない。

### 4. ベースラインと元記述を比較評価

元の記述にあってベースラインにない記述を、1つずつ余分な要素として評価し以下に分類する。

1. どうしても必要: これがないと文書の目的を達成できない
2. 悪くはない: 効果はあるが、なくても目的は達成できる
3. どっちでもいい: あってもなくても成果が変わらない
4. 悪影響: 存在するとむしろ成果が悪くなる

### 5. 提案を返す

ベースラインへ「どうしても必要」だけを戻した本文を提案として返す。

「悪くはない」は戻さず、別案としての並記だけを許可する。
